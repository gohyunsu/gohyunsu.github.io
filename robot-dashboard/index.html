02 · ALGORITHM MAP

Perception → pose → pulse-controlled motion.

SLAM/odometry에 의존하지 않고, 404cm 사각 arena의 벽과 true frame을 기준으로 위치를 잡습니다. 듀얼 카메라는 객체 판별을 맡고 LiDAR는 벽·자세·주행 피드백을 맡습니다.

  1. 01

    LiDAR wall fit

    RPLidar scan에서 사각 arena의 4벽을 robust fit. (x, y, heading, quality)를 true-frame으로 변환.

    TrueFrameLoc · frame_pin.json
  2. 02

    Dual vision verdict

    C920 2대 + YOLO segmentation이 UDP :47021로 detection을 전달. confidence·frame count·mask area gate를 통과해야 goal commit.

    vision_node_dual.py · GEN_MIN_CONF
  3. 03

    Course conductor

    한 프로세스에서 Seq1 C7 sweep → Seq2 R5_R6 channel → corner connector → Seq3–6를 연결. vision node는 prewarm 후 reuse.

    run_course.py → conductor.main()
  4. 04

    Closed-loop primitives

    LiDAR/IMU feedback으로 line·lunge·strafe·turn을 실행. pose quality, stale pose, jump guard를 확인하며 motor command를 갱신.

    motion.py · legs.py · turn.py
  5. 05

    One-shot pulse stop

    along-axis velocity를 추정해 fire point에서 1회 reverse brake. pulse duration은 속도 기반이고, short landing을 우선합니다.

    stop.py · PulseStopper
  6. 06

    ESP mecanum output

    최종 body command가 ESP serial로 전달됩니다. 카메라·teleop가 serial을 잡고 있으면 run을 시작하지 않습니다.

    /dev/ttyACM0 · physical cutoff

03 · TUNING SURFACE

실제 런처에서 읽는 변수.

nav/arena.sh의 run) block이 live default의 기준입니다. 한 run에만 적용하려면 파일을 수정하지 말고 환경변수로 override합니다.

GEN_CMD_MAX120

실제 전체 속도 상한. 약 44 cm/s. 낮추면 모든 leg가 함께 느려집니다.

GEN_CRUISE52

scan/travel drive target. 이미 command cap에 포화하므로 단순히 높이지 않습니다.

GEN_PULSE_CA / CB16 / 0

reverse brake law. calibrated fire band 밖의 속도라면 재보정이 먼저입니다.

GEN_PULSE_BIAS3 cm

일찍 brake를 걸어 short landing. overshoot이면 올리고, short면 내립니다.

GEN_TURN_RATE CW / CCW91 / 92 °/s

open-loop turn pulse 길이를 정하는 값. over/under rotation의 첫 조정점입니다.

GEN_MIN_CONF0.6

모든 Seq의 confidence floor. 낮으면 miss 감소·false eat 증가입니다.

GEN_MIN_FRAMES2

verdict gate. cmd120에서는 객체당 2–3 frame만 확보될 수 있어 무작정 높이면 안 됩니다.

CH_LEAD / COMMIT_LEAD74 cm

object 이전 verdict read 지점. live run의 default lead입니다.

DUAL_TOE R / L+26.9° / −26.9°

카메라 mount를 움직였다면 반드시 재검증해야 하는 물리 calibration입니다.

WALL_D022 cm

실제 arena.sh fallback. lane_x = 404 − WALL_D0. README 표의 20과 다르므로 런처를 우선합니다.

GEN_WALL_ESTOP0 (OFF)

현재 기본값은 wall guard 비활성화. 필요 시 GEN_WALL_ESTOP=1 ./arena.sh run.

GEN_TIMED_HOP0 (OFF)

timed hop은 4–7cm error로 검증되지 않아 closed-loop glide가 기본입니다.

CH_STRAFE_FF0

행 정렬 strafe의 공통 feed-forward offset입니다. 0이면 목표 행에 의도적으로 짧게 서는 bias를 주지 않습니다.

CH_STRAFE_FF_R60

R6 정렬에만 적용하는 추가 strafe feed-forward입니다. 0으로 두어 R6에 별도 pre-offset을 넣지 않습니다.

GEN_STRAFE_YAW_KP3.0

옆이동 중 heading 보정 P gain입니다. strafe가 만들어내는 yaw drift를 잡되, 과도한 값은 흔들림을 키울 수 있습니다.

GEN_YAW_KP3.0

주행 leg 전반의 heading-hold P gain입니다. 낮으면 heading drift, 높으면 steering oscillation 가능성이 있습니다.

GEN_YAW_INNER_DT0.05 s

yaw 내부 제어 갱신 시간 기준입니다. 50ms로 두어 IMU yaw 보정의 업데이트 cadence를 정합니다.

GEN_VOTE_NORMon

goal vote에 range-normalized mask-area gate를 적용합니다. 멀리 있는 물체의 누수와 지나치게 가까운 mismatch를 줄입니다.

GEN_VOTE_MIN_NORM12,000

정규화된 goal mask-area의 하한입니다. 이보다 작은 표는 멀리 있는 객체/약한 검출로 보고 vote에서 제외합니다.

GEN_VOTE_MAX_NORM40,000

정규화된 goal mask-area의 상한입니다. 이보다 큰 표는 너무 가까운 객체나 잘못된 station 귀속 가능성을 줄이기 위해 제외합니다.

RG_RETURN_AFTER3

3개를 수집하면 즉시 goal로 복귀·배출합니다. collector fill limit과 복귀 시점을 함께 정합니다.

RG_REVERSE1 (ON)

배출 뒤 reverse trip을 활성화합니다. C1은 point-blank 판정 문제가 있어 return-look 결과와 함께 반드시 로그를 확인합니다.

RG_HALF_TURN_ONESHOT1 (ON)

180° 방향 전환을 90° 두 번이 아닌 한 번의 pulse로 실행합니다. 적재 상태에서의 retention은 현장 확인이 필요한 위험 항목입니다.

GOAL CLASSES./arena.sh run dodec pineapple_cube이번 run에서 수집 대상으로 취급할 segmentation class입니다.
